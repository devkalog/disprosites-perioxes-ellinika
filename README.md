# Δυσπρόσιτες Courier

**Έκδοση 1.0.0 · Δημιουργία: [Aboutnet](https://aboutnet.gr/)**

Modular plugin για WooCommerce που διαχειρίζεται δυσπρόσιτες περιοχές και χρεώσεις αποστολής για πολλές εταιρείες courier. Κάθε εταιρεία διαθέτει ανεξάρτητη λίστα περιοχών, τιμολογιακή πολιτική και κανόνες απόκρυψης άλλων μεθόδων.

Η αντιστοίχιση απαιτεί πάντα **πόλη και ταχυδρομικό κώδικα**. Δεν απαιτείται προσθήκη της μεθόδου στις ζώνες αποστολής του WooCommerce.

## Χαρακτηριστικά

- Πολλαπλά προφίλ courier με ανεξάρτητες ρυθμίσεις και ενεργοποίηση/απενεργοποίηση.
- Κανονικός τίτλος checkout και προαιρετικός διαφορετικός τίτλος για δωρεάν αποστολή.
- Βασικό κόστος, βασικό βάρος και επιπλέον χρέωση ανά επόμενο ολόκληρο κιλό.
- Φορολογική κατάσταση με προεπιλογή **Χωρίς φόρο** στα νέα προφίλ.
- Προαιρετικό όριο δωρεάν μεταφορικών ανά courier.
- Επιλογή υπαρχουσών μεθόδων αποστολής προς απόκρυψη και υποστήριξη ακριβών rate IDs τρίτων plugins.
- Εισαγωγή CSV με προεπισκόπηση και εξαγωγή λίστας περιοχών.
- Κανονικοποίηση ελληνικών ονομάτων, αφαίρεση διπλοεγγραφών και notices για ελλιπείς εγγραφές.
- Ξεχωριστός indexed πίνακας περιοχών για μεγάλες λίστες.
- Μεταφορά αναγνωρισμένων παλιών ρυθμίσεων ΕΛΤΑ Courier και ACS.
- Έλεγχοι δικαιωμάτων, nonces και validation στις ενέργειες διαχείρισης.

## Απαιτήσεις

- WordPress 6.4 ή νεότερο.
- PHP 7.4 ή νεότερη.
- Ενεργό WooCommerce.
- Βάση MySQL/MariaDB με δυνατότητα δημιουργίας και ενημέρωσης πινάκων/indexes και υποστήριξη named locks.

Οι ελάχιστες εκδόσεις είναι οι δηλωμένες απαιτήσεις του plugin, όχι πλήρης πίνακας δοκιμασμένης συμβατότητας.

## Εγκατάσταση

1. Κρατήστε αντίγραφο ασφαλείας αρχείων και βάσης δεδομένων.
2. Αν αντικαθιστάτε παλιό κώδικα δυσπρόσιτων, απενεργοποιήστε τα αντίστοιχα snippets ώστε να μην εκτελούνται διπλοί κανόνες.
3. Εγκαταστήστε το `disprosites-courier-1.0.0.zip` από **Πρόσθετα → Προσθήκη νέου → Μεταφόρτωση προσθέτου** ή αντιγράψτε τον φάκελο `disprosites-courier` στο `wp-content/plugins/`.
4. Ενεργοποιήστε το plugin με ενεργό WooCommerce.
5. Ανοίξτε **WooCommerce → Courier – Δυσπρόσιτες** και δημιουργήστε προφίλ εταιρείας.
6. Προσθέστε λίστα, χρεώσεις και μεθόδους προς απόκρυψη και δοκιμάστε το checkout πριν τη χρήση σε παραγωγή.

## Ρυθμίσεις εταιρείας

| Πεδίο | Περιγραφή |
| --- | --- |
| Όνομα διαχείρισης | Εσωτερικό όνομα εταιρείας. |
| Τίτλος στο ταμείο | Κανονικός τίτλος της μεθόδου στο checkout. |
| Ενεργοποίηση | Ανενεργό προφίλ δεν δημιουργεί χρέωση και δεν κρύβει άλλες μεθόδους. |
| Χώρα | Η τρέχουσα φόρμα προσφέρει Ελλάδα (GR). |
| Περιοχές | Λίστα στη μορφή `Πόλη,ΤΚ`, μία εγγραφή ανά γραμμή. |
| Βασικό κόστος | Χρέωση μέχρι το βασικό βάρος. |
| Βασικό βάρος | Όριο βάρους σε κιλά. |
| Επιπλέον κόστος ανά kg | Χρέωση ανά επόμενο ολόκληρο κιλό πάνω από το όριο. |
| Δωρεάν μεταφορικά από | Προαιρετικό όριο αξίας συνολικού καλαθιού. |
| Τίτλος όταν τα μεταφορικά είναι δωρεάν | Εναλλακτικός τίτλος όταν ενεργοποιείται το όριο δωρεάν μεταφορικών. Κενό σημαίνει χρήση του κανονικού τίτλου. |
| Φορολογική κατάσταση | Χωρίς φόρο ή φορολογητέο. Προεπιλογή νέων προφίλ: χωρίς φόρο. |
| Απόκρυψη μεθόδων ζωνών | Επιλογή ήδη ρυθμισμένων μεθόδων του καταστήματος. |
| Ακριβή IDs τρίτων μεθόδων | Ένα πλήρες rate ID ανά γραμμή, χωρίς wildcards. |

Οι ζώνες χρησιμοποιούνται μόνο για την επιλογή υπαρχουσών μεθόδων προς απόκρυψη. Δεν χρειάζεται να προσθέσετε εκεί τη μέθοδο δυσπρόσιτων.

### Υπολογισμός χρέωσης

```text
κόστος = βασικό κόστος
       + ceil(max(0, βάρος σε kg − βασικό βάρος)) × επιπλέον κόστος ανά kg
```

Παράδειγμα: βασικό κόστος **5,40 €** έως **2 kg**, επιπλέον κόστος **1,35 €/kg**:

| Βάρος | Χρέωση πριν από τυχόν φόρο αποστολής |
| --- | --- |
| 2,00 kg | 5,40 € |
| 2,10 kg | 6,75 € |
| 3,00 kg | 6,75 € |
| 3,40 kg | 8,10 € |

Ο υπολογισμός γίνεται ανά πακέτο, με ποσότητες προϊόντων και μετατροπή της μονάδας βάρους του καταστήματος σε κιλά. Τα εικονικά προϊόντα δεν προσμετρώνται στο βάρος. Προϊόν χωρίς δηλωμένο βάρος υπολογίζεται ως μηδενικού βάρους.

Οι χρεώσεις εισάγονται χωρίς φόρο. Αν επιλεγεί **Φορολογητέο**, χρησιμοποιούνται οι φορολογικοί κανόνες αποστολής του WooCommerce. Υπάρχουσες αποθηκευμένες φορολογικές επιλογές δεν αλλάζουν αυτόματα.

### Δωρεάν μεταφορικά

Το όριο συγκρίνεται με την αξία προϊόντων **ολόκληρου του καλαθιού μετά από εκπτώσεις/κουπόνια και μαζί με τον ΦΠΑ**, χωρίς μεταφορικά ή πρόσθετα τέλη. Περιλαμβάνονται τα εικονικά προϊόντα και τα προϊόντα άλλων πακέτων αποστολής.

- Η δωρεάν αποστολή ισχύει από το όριο και πάνω.
- Κενό πεδίο: απενεργοποιημένο.
- Τιμή `0`: πάντα δωρεάν για τις περιοχές του συγκεκριμένου προφίλ.
- Μηδενίζεται μόνο η χρέωση του συγκεκριμένου courier, όχι όλων των μεθόδων του καταστήματος.
- Η διεύθυνση πρέπει να ταιριάζει κανονικά στη λίστα δυσπρόσιτων.
- Αν έχει συμπληρωθεί εναλλακτικός τίτλος, π.χ. **ACS – Δωρεάν αποστολή**, εμφανίζεται όταν ενεργοποιείται το όριο. Διαφορετικά διατηρείται ο κανονικός τίτλος.

### Απόκρυψη μεθόδων

Οι κανόνες απόκρυψης εφαρμόζονται μόνο όταν υπάρχει διαθέσιμη χρέωση του αντίστοιχου προφίλ για το συγκεκριμένο πακέτο. Χωρίς αντιστοίχιση, οι άλλες μέθοδοι παραμένουν ως έχουν.

Η επιλογή ενός method instance κρύβει όλες τις επιμέρους τιμές του. Για απόκρυψη μίας συγκεκριμένης τιμής τρίτου plugin, χρησιμοποιήστε το πλήρες rate ID, π.χ. `flexible_shipping_single:5`.

Αν ταιριάζουν πολλές εταιρείες, εμφανίζονται όλες με τις δικές τους τιμές. Η μία δεν κρύβει την άλλη.

## Μορφή λίστας και CSV

```csv
city,postcode
ΠΕΡΙΟΧΗ Α,12345
"ΠΕΡΙΟΧΗ Β",54321
```

Οι εγγραφές του παραδείγματος είναι ενδεικτικές και **δεν αποτελούν επίσημη λίστα δυσπρόσιτων**.

- CSV UTF-8, έως **2 MB**, με κόμμα ως διαχωριστικό. Η κεφαλίδα `city,postcode` είναι προαιρετική.
- Μία εγγραφή ανά γραμμή. Οι πόλεις που περιέχουν κόμμα πρέπει να περικλείονται σε εισαγωγικά.
- Εισαγωγικά γύρω από ονόματα με κενά είναι φυσιολογική μορφοποίηση CSV και δεν επηρεάζουν την αντιστοίχιση.
- Τόνοι, διαλυτικά, πεζά/κεφαλαία και διαδοχικά κενά στις πόλεις κανονικοποιούνται. Τα κενά στους ΤΚ αφαιρούνται.
- Η αντιστοίχιση απαιτεί **και πόλη και ΤΚ**. Δεν γίνεται αντιστοίχιση μόνο βάσει ΤΚ, fuzzy matching, διόρθωση ορθογραφίας ή μετατροπή Greeklish.
- Οι διπλοεγγραφές αφαιρούνται. Τα αρχικά μηδενικά στους ΤΚ διατηρούνται· προσέξτε τη μορφοποίηση κελιών σε εφαρμογές υπολογιστικών φύλλων.
- Εγγραφές όπως `ΒΡΥΟΝΗΣΙ,` ή `,12345` παραλείπονται και εμφανίζεται notice με πλήθος, γραμμές, περιεχόμενο και πεδία που λείπουν.
- Άλλα σφάλματα, όπως λανθασμένα εισαγωγικά, επιπλέον στήλες ή μη έγκυρος ΤΚ, εμποδίζουν την αποθήκευση.
- Ενεργό προφίλ δεν μπορεί να αποθηκευτεί με κενή λίστα.

Η **εισαγωγή CSV φορτώνει προεπισκόπηση** και αντικαθιστά το περιεχόμενο του πεδίου, χωρίς αυτόματη αποθήκευση. Ελέγξτε τη λίστα και πατήστε **Αποθήκευση προφίλ**. Η εξαγωγή αφορά τις περιοχές, όχι πλήρες backup ρυθμίσεων.

## Αποθήκευση δεδομένων

- Οι ρυθμίσεις αποθηκεύονται στο μη-autoload option `dcp_courier_profiles`.
- Οι περιοχές αποθηκεύονται στον πίνακα `{prefix}dcp_areas`, με ανεξάρτητο αναγνωριστικό εταιρείας και συνόλου εγγραφών.
- Η αναζήτηση χρησιμοποιεί σύνθετο index εταιρείας, συνόλου και hash πόλης/ΤΚ, με επιπλέον έλεγχο ακριβούς ισότητας στην PHP.
- Το checkout δεν φορτώνει ολόκληρα CSV. Οι πλήρεις λίστες φορτώνονται μόνο για επεξεργασία/εξαγωγή στο διαχειριστικό.
- Νέα λίστα γίνεται ενεργή μόνο αφού γραφτούν και επαληθευτούν όλες οι εγγραφές. Σε αποτυχία παραμένει ενεργή η προηγούμενη.
- Οι αλλαγές προφίλ προστατεύονται με named lock. Η cache αποστολών ανανεώνεται μέσω μικρού δείκτη αλλαγών και της συνολικής αξίας καλαθιού.
- Παλιά σύνολα διατηρούνται για τουλάχιστον 24 ώρες για αιτήματα σε εξέλιξη και καθαρίζονται σε επόμενη επιτυχημένη αποθήκευση της ίδιας εταιρείας.
- Η διαγραφή εταιρείας αφαιρεί και τις περιοχές της. Η απενεργοποίηση ή αφαίρεση του plugin δεν εκτελεί αυτόματη διαγραφή των δεδομένων του.

### Μεταφορά υφιστάμενων δεδομένων

Υποστηρίζεται εισαγωγή από τις αναγνωρισμένες πηγές:

| Παλιό method ID | Option |
| --- | --- |
| `custom_elta_courier` | `woocommerce_custom_elta_courier_settings` |
| `custom_acs` | `woocommerce_custom_acs_settings` |

Κάθε πηγή εισάγεται ανεξάρτητα και μόνο μία φορά. Μεταφέρονται τίτλος, λίστα, χρεώσεις και ενεργοποίηση, χωρίς διαγραφή των αρχικών options. Hardcoded κανόνες απόκρυψης, σειρά εμφάνισης και κανόνες δωρεάν αποστολής από παλιό PHP snippet **δεν μεταφέρονται αυτόματα**.

Υποστηρίζεται επίσης αυτόματη μεταφορά προφίλ που έχουν λίστες ενσωματωμένες στα options. Η αρχική λίστα αφαιρείται από το option μόνο μετά την επιτυχή εγγραφή στον πίνακα. Μη έγκυρες ή ελλιπείς παλιές εγγραφές απαιτούν έλεγχο από το διαχειριστικό.

> Μην χρησιμοποιήσετε παραγωγικό checkout όσο εμφανίζεται σφάλμα μεταφοράς: μη μεταφερμένα προφίλ δεν παράγουν χρέωση δυσπρόσιτης. Για επαναφορά παλιάς αποθήκευσης απαιτείται και αντίστοιχο backup βάσης, όχι μόνο παλιό ZIP.

## Περιορισμοί και συμβατότητα

- Δεν περιλαμβάνονται επίσημες λίστες courier, σύνδεση με API, έκδοση vouchers ή tracking.
- Αν είναι ενεργή η ρύθμιση WooCommerce που αποκρύπτει άλλες μεθόδους όταν υπάρχει δωρεάν αποστολή, μπορεί να αφαιρεθούν οι χρεώσεις δυσπρόσιτων πριν εφαρμοστούν οι κανόνες του plugin. Ελέγξτε τη σχετική προειδοποίηση στο διαχειριστικό.
- Άλλα plugins που περιορίζουν μεθόδους αποστολής ή αλλάζουν φόρους μπορούν να επηρεάζουν το αποτέλεσμα.
- Δεν παρακάμπτονται οι περιορισμοί χωρών αποστολής του WooCommerce.
- Τα σφάλματα και οι προεπισκοπήσεις διατηρούν τα πεδία προσωρινά ανά χρήστη για έως 15 λεπτά και μία προβολή. Η ανανέωση της σελίδας μετά την προβολή δεν επαναφέρει την προσωρινή φόρμα.
- Πριν τη χρήση σε παραγωγή δοκιμάστε Classic Checkout, Checkout Block, κουπόνια, φόρους, δωρεάν αποστολή και τις πραγματικές μεθόδους του καταστήματος.

## Ανάπτυξη και έλεγχοι

Δεν απαιτούνται Composer ή npm dependencies για το build ή την αυτοτελή σουίτα.

```sh
php tests/run.php
```

Συντακτικός έλεγχος σε PowerShell:

```powershell
Get-ChildItem -Recurse -Filter *.php | ForEach-Object { php -l $_.FullName }
```

Η αυτοτελής σουίτα περιλαμβάνει **40 tests / 567 assertions** με υποκατάστατα WordPress/WooCommerce και storage. Καλύπτει CSV, αντιστοίχιση, χρεώσεις, δωρεάν μεταφορικά, εναλλακτικό τίτλο, διαχείριση, μεγάλες λίστες και αποτυχίες αποθήκευσης. Έχει εκτελεστεί με και χωρίς `mbstring`.

Η δοκιμή βάσης έχει εκτελεστεί με πραγματικά WordPress options, `wpdb`, `dbDelta` και MariaDB, με δύο λίστες των 10.000 ελληνικών εγγραφών και **28 ελέγχους**. Ελέγχθηκαν indexes με `EXPLAIN`, μεταφορά, εξαγωγή, αποτυχημένα INSERT/UPDATE, διατήρηση προηγούμενης λίστας και διαγραφή. Δεν αποτελεί πλήρη δοκιμή WooCommerce checkout.

Για επανάληψη σε Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\tests\run-db.ps1
```

Ο runner απαιτεί τοπική PHP/MariaDB (προεπιλογές XAMPP), σύνδεση για λήψη επίσημου WordPress και ελεύθερη θύρα `13316`. Δημιουργεί απομονωμένη προσωρινή βάση και σταματά τον προσωρινό server μετά τη δοκιμή.

### Δημιουργία ZIP

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Παράγεται το `dist/disprosites-courier-1.0.0.zip`, με τον φάκελο του plugin και το README, χωρίς tests και build scripts.
